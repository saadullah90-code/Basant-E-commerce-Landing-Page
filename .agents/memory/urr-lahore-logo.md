**Why:** The user noticed clipping in the header during visual review, and correcting it required checking how the transparent canvas sits inside the compact navigation.

**How to apply:** When changing the header or footer dimensions, verify the full logo in desktop and mobile previews. Only remove demonstrably transparent padding if a tighter asset is needed; never crop or alter visible artwork.
