# 13. WHATSAPP INTEGRATION — FLOATING CHAT BUTTON

**A functional WhatsApp button is mandatory. Do not skip this feature.**

Add a floating WhatsApp button that allows visitors to contact the client directly from anywhere on the landing page.

## A. Floating WhatsApp button

- Position the button at the bottom-right corner of the viewport.
- Keep it visible while visitors scroll.
- Use the official WhatsApp icon.
- Use WhatsApp green: #25D366.
- Use a recognizable white WhatsApp icon.
- Add a subtle shadow and polished hover effect.
- Include a gentle entrance animation.
- On desktop, optionally show a small "Chat with us" label.
- On mobile, use a compact, easy-to-tap button.
- Ensure it does not overlap product buttons, checkout actions, or mobile navigation.
- Use an accessible label such as "Chat with us on WhatsApp".
- Keep the button above decorative elements through appropriate stacking order.

The design must complement the colorful Basant website while preserving the recognizable WhatsApp branding.

Do not make the button excessively large, flashy, or distracting.

## B. WhatsApp phone number configuration

Use the official WhatsApp click-to-chat URL format:

`https://wa.me/WHATSAPP_NUMBER?text=ENCODED_MESSAGE`

Requirements:

- Use the client's actual WhatsApp number.
- Do not invent or assume the phone number.
- Until the number is provided, use a clearly marked configuration placeholder.
- For Pakistani numbers, use country code `92`, without the leading zero, spaces, or plus sign.
- Keep the number in one centralized configuration variable or suitable environment-based configuration.
- Generate the message using JavaScript URL encoding.
- Open the correct WhatsApp conversation using a valid URL.
- Use an appropriate new-tab behavior for external links.

Example configuration placeholder:

`WHATSAPP_NUMBER = "REPLACE_WITH_CLIENT_NUMBER"`

Ensure the implementation is easy to configure after the client provides their number.

## C. Default WhatsApp message

Use the following pre-filled message for the floating button:

"Assalam-o-Alaikum! I'm interested in your Basant Collection. Please share more details."

When the visitor clicks the button, WhatsApp should open with this message already populated.

Do not automatically send messages. The visitor must review and send the message themselves.

## D. Product-specific WhatsApp inquiry buttons

Add an optional "Inquire on WhatsApp" or "Order via WhatsApp" button to each product card or product detail interaction.

When clicked, dynamically create a WhatsApp message using the actual product data.

Example:

"Assalam-o-Alaikum! I'm interested in [Product Name] from your Basant Collection. Please share its price and availability."

If the product has actual selectable variants, include the selected size, color, or variant in the message.

If the actual product price is available, it may also be included. Never invent missing prices or variants.

Use the centralized product data structure. Do not hardcode separate messages for individual products.

## E. WhatsApp functionality and limitations

The WhatsApp integration should open a conversation with the client's configured business number.

It does not automatically process payments, reserve stock, create Shopify orders, or complete checkout unless those features are separately implemented.

Do not describe the website as having fully automated WhatsApp ordering when it only opens a pre-filled chat.

## F. WhatsApp testing

Verify:

1. The floating button appears on desktop and mobile.
2. The configured phone number produces a valid WhatsApp URL.
3. The default message is correctly encoded.
4. Product inquiry messages contain the correct product name.
5. Selected variants are included when relevant.
6. The button does not obstruct other important interactions.
7. The link opens correctly and leaves message sending under the visitor's control.

# 14. ANIMATION AND MOTION DESIGN SYSTEM

The website must feel alive, immersive, and interactive without sacrificing performance or usability.

Implement the following where appropriate:

1. Floating kites in the hero.
2. Subtle kite-string movement.
3. Layered parallax.
4. Staggered hero typography.
5. Seamless announcement marquee.
6. Seamless festive marquee.
7. Refined product image hover effects.
8. Button hover and press states.
9. Scroll-triggered section reveals.
10. Sticky header transitions.
11. Subtle decorative environmental movement.
12. Floating WhatsApp button entrance and hover effects.

### Motion quality rules

- Use natural easing.
- Vary animation timing according to the element.
- Avoid repetitive, mechanical movements.
- Avoid flashing, excessive spinning, or unnecessary bouncing.
- Do not animate every element at once.
- Keep animations lightweight.
- Respect `prefers-reduced-motion`.
- Simplify animations on mobile.
- Avoid layout shifts caused by animation.
- Prefer CSS transforms for decorative movement.
- Use IntersectionObserver where suitable for scroll-triggered reveals.

Animation should reinforce the visual storytelling, not distract visitors from the products.
